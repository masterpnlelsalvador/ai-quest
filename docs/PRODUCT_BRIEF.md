# AI Quest — Product Brief · v0.1

## Problem

Many AI training resources evaluate the shape of a prompt without evaluating how users make decisions while working with AI. Professionals also lose reusable knowledge in long chats, share more context than needed, and mistake low token consumption for useful productivity.

## Product hypothesis

An interactive browser practice lab plus a practical work-planning tool can help employees learn transferable AI habits and share effective methods. This is a **hypothesis**, not a validated business claim. The local candidate is MIT-licensed but has not been published.

## Intended audience

Employees using AI for support, engineering, documentation or business processes. No programming knowledge required for the browser demo.

## Promise

**Learn by doing. Practice your judgment. Share what works after release approval.**

## Success for v0.1

A first-time user can (a) launch the web app, (b) finish each of three missions, (c) see a transparent result with corrective feedback, and (d) generate a safe work-plan template, without authentication, AI API keys or uploads.

## Non-goals

- Professional credentialing or objective measurement of general employee competence.
- Production incident response, policy enforcement or enterprise integrations.
- Real token usage measurement, analytics collection or AI-generated ratings.
- Sharing secret credentials, personal data, raw internal support tickets or genuine customer records.
- Building a fully-fledged LMS, organization dashboard or multiplayer product.

## Functional requirements

1. **Safety mission:** Select relevant lines from synthetic logs; touching any sensitive line yields a critical flag.
2. **Context mission:** Select important facts for a handoff; noise and missing crucial context reduce results.
3. **Efficiency mission:** Sequence limited-cost actions to investigate, verify, and communicate a fictional incident.
4. **Workbench:** Select task, information classification and session mode; create a downloadable Markdown template.
5. **Review:** Transparent scoring, explanations, retry path, progress visible within the tab.
6. **Portability:** Zero paid services; static deployment; documented installation and GitHub sharing instructions.

## Experience principles

- Decision first; feedback second.
- Safe synthetic data only.
- No public performance leaderboard in v0.1.
- Error states explain consequences without shaming users.
- Mobile responsive, keyboard-accessible, understandable English.

## Deployment stance

Local candidate in v0.1. Public release only after manual security/UX review and explicit authorization. Do not publish user/private company material. Separate repository from Agent Gauntlet.
