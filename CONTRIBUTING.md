# Contributing to AI Quest

AI Quest is public under the MIT License. Review the existing missions, rubric and tests before proposing a change.

Propose changes that improve a practical decision, its explanation or accessibility through an issue or pull request. Use only fictional data. State the scenario goal, scoring rules, failure conditions and what the result can and cannot demonstrate. Add meaningful deterministic tests for changed scoring or feedback.

Do not submit customer or employee data, real credentials, private policies, pilot answer keys, participant responses, analytics, external APIs or dependencies without a separate review. Scores must never be presented as professional certification.
