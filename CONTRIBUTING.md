# Contributing to AI Quest

This candidate is prepared for review under the MIT License; no public repository or contribution process is open yet.

When a repository is authorized, propose changes that improve a practical decision, its explanation or accessibility. Use only fictional data. State the scenario goal, scoring rules, failure conditions and what the result can and cannot demonstrate. Add meaningful deterministic tests for changed scoring or feedback.

Do not submit customer or employee data, real credentials, private policies, pilot answer keys, participant responses, analytics, external APIs or dependencies without a separate review. Scores must never be presented as professional certification.
